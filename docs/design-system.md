# ISOTROPE Design System

## Visual direction

**Minimal Industrial Intelligence**

The site should feel technical, precise, premium and differentiated from conventional rope-access and industrial-service websites.

Core principle:

> ISOTROPE is not a company of people hanging from ropes. It is a technical company that solves problems in hard-to-reach places.

Visual hierarchy:

**Engineering → Systems → Precision → Access → Rope**

## Color system

Primary palette:

- White: `#FFFFFF`
- Off-white: `#F4F4F3`
- Light grey: `#C9CACE`
- Secondary grey: `#74777D`
- Primary black: `#08090B`
- Primary purple: `#7F00B2`
- Purple hover/active: `#9300CF`
- Deep purple: `#4E006B`
- Dark surface: `#111216`
- Elevated surface: `#191A1F`
- Dark border: `#292B31`
- Technical dark grey: `#474A51`
- Muted text: `#8E9198`
- Light border: `#D9DADD`
- Alternate light background: `#F8F8F8`
- Auxiliary grey: `#B7B9BE`

Purple is a precision accent. Use it primarily for CTAs, active states and small controlled details. Avoid large purple background fields.

Avoid orange, yellow and red as primary brand colors.

## Typography

- Display / headings: **Instrument Sans**
- Body / UI: **Manrope**

## Hero visual rules — LOCKED

The approved Hero baseline is `frontend/hero/isotrope-hero-v14-LOCKED.html`.

Protected characteristics:

- Large editorial uppercase headline
- Negative/radiographic effect using `mix-blend-mode:difference`
- Neutral white x-ray edge and sweep
- No purple tint in the main headline
- Purple used only as controlled CTA/accent color
- B&W / neutral architectural or technical video treatment
- Pill buttons
- No arrows or decorative CTA icons
- Edge-to-edge desktop composition
- Responsive breakpoints at 1000px and 750px

## CTA system

Primary Hero CTA:

`REQUEST A CALLBACK`

Secondary Hero CTA:

`BOOK A CONSULTATION`

Primary button:
- Purple fill
- Purple border
- White text
- Hover: white border

Secondary button:
- Dark/translucent surface
- Subtle white border
- Hover: purple border

## Navigation

Current navigation direction:

- Home
- About
- Services
- Projects

Contact is intentionally omitted from the main navigation and handled through CTA-driven contact actions.

## Imagery

Prefer:
- architecture
- hard-to-reach environments
- facade/technical contexts
- minimal black-and-white photography/video

Avoid:
- generic worker-abseiling silhouettes as a brand motif
- cliché rope-access imagery as the primary identity
- predictable industrial palettes and visual tropes
